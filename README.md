Сделать сервис по созданию, получению, обновлению, удалению групп.
Создать это в apps/groups
В базе данных находится модель Group. Её поля:
id - UUID
name - text (название группы, должно быть уникальным)
description - text (описание группы)
List[Students] - список студентов (https://github.com/SENATAI/backendTestTaskItSchool/blob/main/school_site/apps/students/models.py), которые относятся к данной группе. Связь - многие ко многим. (Для модели студента так же добавить List[Groups]) 
Teacher - преподаватель. Сейчас это просто user_id (в дальнейшем будет отдельная таблица с преподавателями), связь с User (https://github.com/SENATAI/backendTestTaskItSchool/blob/main/school_site/apps/users/models.py) - многие к одному
Course - курс, к которой привязана данная группа. Сейчас это поле НЕ НУЖНО реализовывать (просто, чтобы не забыть).
created_date и updated_date - наследование от TimestampMixin
P.S. Естественно в самом коде в моделях должно быть не просто List[Students] через relationship, но и сам список id-шников, в общем, по базе как это работает в sqlalchemy

Запросы, на которые должен отвечать сервис:

POST: /api/groups/ - добавление группы, в тело запроса обязательно передаются поля name, description. Если модель с таким name уже существует - выдать ошибку, статус 409. Статус успешного ответа - 201. 

GET: /api/groups/ - получение всех групп. Нужно вывести списком все модели только с полями id, name (+пагинация). Статус успешного ответа - 200

GET: /api/groups/{id}/ - получение определённой группы. Нужно вывести группы со всеми полями по заданному id (все поля только этой модели, поля других моделей, которые связаны с ней пока не трогать). Вывести ошибку, если такой группы нет, статус - 404. Статус успешного ответа - 200

PUT: /api/groups/{id}/  - обновление группы, в тело запроса обязательно передаются поля name, description. Вывести ошибку, если такой группы нет, статус - 404. Если модель с таким name уже существует - выдать ошибку, статус 409. Статус успешного ответа - 200. 

DELETE: /api/groups/{id}/ - удаление определённой группы. Нужно удалить группу по заданному id. Выводить ошибку, если такой группы нет не нужно. Статус успешного ответа - 204

POST /api/groups/{group_id}/students/ - добавление студентов к группе. В тело запроса передаётся список students_id которые нужно добавить к данной группе. Проверить на то, что все students_id реально существуют, иначе ошибка 404, аналогично, если нет группы. Статус успешного ответа - 200.

DELETE /api/groups/{group_id}/students/{student_id} - удаление студента из группы. Тела запроса нет, всё берётся из url. Всегда статус 204.

POST /api/groups/{group_id}/teacher/ - добавление преподавателя к группе. В тело запроса передаётся teacher_id который нужно добавить к данной группе. Проверить на то, что teacher_id реально существует, иначе ошибка 404, аналогично, если нет группы. Если у группы уже есть teacher - 409 ошибка. Статус успешного ответа - 200.

DELETE /api/groups/{group_id}/teacher/{student_id} - удаление преподавателя из группы. Тела запроса нет, всё берётся из url. Всегда статус 204.
